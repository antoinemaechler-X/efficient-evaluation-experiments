***************************************************************************************************************************
NOTES


Some variables from the previous American News Pathways waves have been added to this dataset so that crosstabs for those key variables can be analyzed with this wave. 
Variables included:
- GROUP_TRUST_a_W57
- NEWS_MOST_W57
- TALKPOL_W57
- FOLELECT_W57
- COVIDNEWSRELY_W66

Created variables include:
- CR_PARTYNEWSUSE_W73
- CR_NEWS_INFLU_W57
- CR_DIG_SAV_W57
- CR_MAINSOPOL_GROUPS_W57
- CR_KNOWLEDGE_INDEX_W57

The following variables have been backcoded based on open-end responses:
- COVIDMVWYMOD_W79 (including 2 additional options that were not asked in the survey but got added based on backcoding; these options are labeled (VOL.) in the topline)
- COVIDMVWREMOD_W79 (including an additional option that wasnot asked in the survey but got added based on backcoding; this option is labeled (VOL.) in the topline)
- COVIDMVIN_W79 (including items f and g that were not asked in the survey but got added based on backcoding; these items are labeled (VOL.) in the topline)
- COVIDMVINWHY_W79 (including 4 additional options that were not asked in the survey but got added based on backcoding; these options are labeled (VOL.) in the topline)

For a small number of respondents with high risk of identification, certain values have been randomly swapped with those of lower risk cases with similar characteristics.


***************************************************************************************************************************
WEIGHTS 

WEIGHT_W79 is the weight for the sample. Data for all Pew Research Center reports are analyzed using this weight.
